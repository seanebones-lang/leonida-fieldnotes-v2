# Leonida Fieldnotes — free fan companion

Owner request: fully interactive GTA VI map to publish, including Easter eggs and hidden locations. Sean explicitly chose a free fan companion first.

Decision: NARROW to a free browser-local field atlas. Existing alternatives include GTABase, MyGTA6Map and MapGenie; current feature research shows crowded coverage and no evidence of commercial demand. Aim for uncluttered phone use, unlimited private pins/notes, spoiler controls and portable backups. No revenue/adoption promise, ads, accounts, new spend or paid APIs.

Data gate: use explicitly licensed/public-domain basemap only after original-source verification; preserve official vs creator-reported vs approximate status. No copied competitor databases, invented precise coordinates, claims of personal in-game verification or Rockstar affiliation. Map asset/data completeness and public audience are separate from functional engine testing.

First version: map pan/zoom, keyboard/touch, search/category filters, source-backed locations, progressive spoiler reveal, found/favorite tracking, personal pins/notes, JSON backup import/export, shareable location links. All progress private in browser; no cloud-sync claim.

Amendment (2026-11-26, owner request): with the game released, the guide corpus expands to the full companion Sean asked for — Easter eggs, hidden locations, free vehicles, free garages, money-making, collectibles, services and unlocks — sourced from published post-release guides. The data gate above is unchanged: every entry carries its source and confidence tier, conflicting figures are recorded as disputes rather than smoothed over, and nothing receives a pin without reliable coordinate evidence.

Amendment (2026-11-26, owner direction "make it the best map"): the community pin layer now imports GTADB.ORG's landmarks dataset — the upstream community dataset this project's own July 2025 snapshot derived from — under its CC BY 4.0 license, with the attribution "GTA VI Landmarks Data (CC BY 4.0) — https://map.gtadb.org" carried in the app, footer, and data source block. The "no copied competitor databases" gate bars scraping rival products' databases; it does not bar importing the openly licensed upstream dataset with attribution. Import rules: existing Fieldnotes IDs and positions never move (notebook data keys on them), new pins are labelled approximate/unconfirmed community data, per-place photos are recorded as URLs under the same CC BY 4.0 credit, and no pin is ever presented as personally verified. Method and validation numbers: research/refresh-gtadb-2026-11-26.py and README.md.

Amendment (2026-11-26, showcase build; owner: "our own custom map, everything findable, nothing hidden — make this a showcase piece"): the default basemap is now our own custom-drawn map of Leonida, vectorised and rendered entirely by our pipeline in canonical world space (pins native, no transform), in day and night GTA VI-themed editions. Architecture correction, recorded honestly: the first showcase attempt put Rockstar's official poster underneath and warped pins onto it; it failed its own accuracy gate (best leave-one-out town median 146.8 poster px against a 28.9 px bar — an information floor, not a fitting failure), so the poster became an optional reference toggle carrying the achieved warp and an explicit "approximate" label, and the community reconstruction stays as a third base. Licensing posture for the poster: © Rockstar Games, fan use, not affiliated, removable on request — the earlier "no official artwork bundled" line is superseded by this amendment for the poster tiles only. Findability is the product: fuzzy search over everything, near-here lists, category progress, curated trails; no spoiler concealment anywhere. Case study: research/official-base-build-2026-11-26.md (part 2).

Amendment (2026-11-26, v2 WebGL rebuild; owner: "start over in a new repo — use advanced graphics", benchmark: State of Leonida as the minimum standard): the renderer is rebuilt on MapLibre GL JS (WebGL) in the new repo seanebones-lang/leonida-fieldnotes-v2, while v1 stays live until v2 beats it. The data gate is unchanged and binds v2 exactly as it binds v1: GTADB under CC BY 4.0 with attribution, our own drawn basemap, Rockstar's poster under fan use — and State of Leonida is a *feature benchmark only*; none of its data files, tiles or code are copied or scraped. Architecture: the flat canonical world rides MapLibre's geographic engine through an inverse-Mercator latitude bridge (longitude linear in worldX), so GPU clustering and pin layers align exactly with the existing tile pyramids; the poster base uses the same bridge at 1/8192 world scale with its tile zooms renumbered −2/−1/0 → 1/2/3 (tile bytes unchanged). Notebook compatibility is a hard requirement, not a goal: same storage key `leonida-fieldnotes:v1`, same state shape including `pinOff`, same backup export/import format and merge rules — a v1 notebook loads in v2 untouched. No concealment or reveal mechanics: the map is a finder. Full record: BUILD-REPORT.md.
